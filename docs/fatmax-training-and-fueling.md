# FatMax, Easy Running, Fuel Use and Recovery — Working Notes

Date: 2026-10-07

## Purpose

Capture the training and physiology conclusions from the discussion about:

- LT1 / LT2 anchors from the laboratory lactate test
- likely FatMax / maximal fat oxidation intensity
- how FatMax running differs from ordinary easy running
- how to structure and analyse FatMax sessions
- fuel use during prolonged running
- cardiovascular drift
- refuelling strategy for fat-loss-oriented easy running versus quality sessions

This note deliberately separates **measured laboratory values** from **current working estimates**.

## 1. Laboratory anchors — measured values

From the August 2026 lactate test:

| Metric | Measured result |
|---|---:|
| LT1 heart rate | **144 bpm** |
| LT1 pace | **6:34 min/km** |
| LT1 speed | **~9.1 km/h** |
| LT2 heart rate | **165 bpm** |
| LT2 pace | **5:17 min/km** |

These are historical measured values and should remain unchanged in the data model.

### Interpretation

- LT1 represents the aerobic threshold / first meaningful lactate rise.
- LT2 represents the higher threshold above which lactate accumulation becomes much harder to stabilise.
- The lab did **not** directly measure FatMax because no respiratory gas analysis / RER measurement was performed.

## 2. FatMax hypothesis

The earlier discussion was corrected to focus on **LT1 rather than LT2**.

The working idea is that peak fat oxidation is likely to occur somewhat below or around the lower aerobic threshold, not around LT2.

### Lab-faithful estimate

Using the measured LT1 of **144 bpm**, the practical FatMax estimate is:

- likely range: **~133–140 bpm**
- practical target: **~135–140 bpm**

### Current practical estimate

Post-test running suggests aerobic economy has improved, but that is not sufficient evidence by itself to move the LT1 heart-rate anchor.

The current practical FatMax model therefore remains:

- measured LT1 reference: **144 bpm**
- practical FatMax range: **~138–145 bpm**
- practical bullseye: **~142 bpm**

This is an estimate, not a measured metabolic threshold. Pace at a given HR can improve without the LT1 HR itself necessarily moving.

## 3. Current working threshold model

The 7 October 2026 threshold session replaces the previous high-HR provisional LT2 estimate for training purposes.

| Metric | Current working value |
|---|---:|
| LT1 training reference | **144 bpm measured** |
| LT2 / LTHR centre | **~167 bpm** |
| LT2 practical HR range | **~164–170 bpm** |
| LT2 pace centre | **~4:55 min/km** |
| LT2 practical pace range | **~4:50–5:00 min/km** |
| FatMax practical range | **~138–145 bpm** |
| FatMax target | **~142 bpm** |

The historical laboratory LT2 remains **165 bpm at 5:17/km** and should remain stored separately.

The current LT2 value is a **working training estimate**, not a new blood-lactate measurement. It is supported by the 7 October 3 × 8 minute session, where approximately 4:50/km was repeatedly produced with late-repetition HR generally in the mid-to-high 160s, and by comparison with the Cheltenham Half Marathon where approximately the same pace carried a much higher race HR.

The previous provisional model of **~176–181 bpm / ~179 bpm central LT2** is retired. That range is better interpreted as hard race / above-threshold cardiovascular demand rather than the threshold anchor.

## 4. Easy run versus FatMax run

A FatMax run is **not a different physiological zone** from easy aerobic running. It is a deliberately narrower target inside the easy/aerobic range.

### Current working ranges

| Run type | HR range |
|---|---:|
| Recovery / very easy | **~125–135 bpm** |
| Easy aerobic | **~135–149 bpm** |
| FatMax-targeted | **~138–145 bpm** |
| FatMax bullseye | **~140–143 bpm** |
| Measured LT1 reference | **144 bpm** |

### Key distinction

A normal easy run can tolerate broader variation.

A FatMax session is more controlled:

- flatter terrain preferred
- HR is the primary target
- pace is secondary
- minimise unnecessary HR spikes
- target approximately **142 bpm**
- practical allowable range around **138–145 bpm**

---

## 5. Pace guidance

The measured LT1 pace was **6:34/km at 144 bpm**.

That pace is useful as a starting reference for FatMax work, but it should **not** override HR.

Practical rule:

> Run whatever pace currently produces approximately 140–145 bpm, ideally around 142 bpm.

Examples:

- if 6:34/km now gives ~142 bpm, that is a useful match
- if improved fitness means 6:15/km gives ~142 bpm, use 6:15/km
- if heat, fatigue or terrain means 6:34/km gives 150 bpm, slow down

The HR response should win over historical pace.

## 6. Practical FatMax workouts

### 40-minute version

Suitable for a short evening run:

- 5 min easy warm-up
- 30 min at **140–145 bpm**, target ~142 bpm
- 5 min easy cool-down
- initial pace reference ~6:30–6:40/km
- HR remains the primary control variable

Expected distance at 6:34/km for the whole 40 minutes would be about **6.1 km**, but realistic total distance with warm-up/cool-down is approximately **5.7–6.1 km**.

### 65–75-minute version

Suitable when the objective is a dedicated low-fatigue fat-oxidation session:

- 10 min easy warm-up
- 50–60 min at **140–145 bpm**
- 5 min easy cool-down

Likely total distance roughly **10–11 km**, depending on the pace required to hold target HR.

### 90-minute FatMax field test

The 90-minute version is primarily useful as a **field test**, not because fat burning requires 90 minutes.

Structure:

- warm up separately
- 90 min continuous at approximately **140–145 bpm**
- cool down separately

There are **no rests** between analytical blocks.

The watch can record the entire session continuously. Post-run analysis should divide the 90-minute target section into:

- 0–15 min
- 15–30 min
- 30–45 min
- 45–60 min
- 60–75 min
- 75–90 min

For each block, compare:

- average HR
- average pace
- cadence
- HR-to-pace relationship
- cardiac drift / aerobic decoupling

No lap presses are required during the run.

## 7. Why FatMax work does not need to be very long

Fat oxidation begins from the start of exercise.

The body does **not** operate as:

1. blood sugar first
2. then muscle glycogen
3. then fat only after glycogen is exhausted

Instead, carbohydrate and fat are used concurrently from the beginning.

The relative contribution changes with:

- intensity
- duration
- training status
- recent nutrition
- glycogen availability
- temperature and hydration

Therefore:

- a 40–60 minute FatMax run is still useful
- 90 minutes is not required for the body to "switch on" fat burning
- a longer session mainly increases total time and total energy expenditure at that intensity

---

## 8. Fuel use during running

Main energy sources overlap:

- blood glucose
- liver glycogen
- muscle glycogen
- circulating fatty acids / intramuscular fat

Muscle glycogen can be used directly by working muscle.

The liver also releases glucose to help maintain blood glucose.

At easy / FatMax intensity, fat oxidation should already make a substantial contribution early in the session.

As duration increases:

- muscle glycogen gradually declines
- fat availability and utilisation can increase
- carbohydrate remains useful even during prolonged aerobic exercise

Severe glycogen depletion is **not** required or desirable simply to achieve high fat oxidation.

---

## 9. Heart-rate drift is not a glycogen-empty signal

During a long steady run, HR can rise despite constant pace.

Example:

- early: 6:34/km at 140 bpm
- later: 6:34/km at 148 bpm

This is commonly explained by **cardiovascular drift**, driven by factors such as:

- rising body temperature
- sweating
- reduced plasma volume
- lower stroke volume
- increased cardiovascular demand for thermoregulation

Fuel depletion may contribute during sufficiently long exercise, but increasing HR should not be interpreted automatically as a switch from carbohydrate to fat.

## 10. Post-run fueling and weight-loss strategy

The principle agreed in discussion is:

> Fuel for the work required.

Weight loss should come from the overall energy balance across days and weeks, not from intentionally sabotaging recovery.

### FatMax / easy session

For a ~40–75 minute FatMax or easy aerobic run:

- water is often enough during the run
- carbohydrate during the run is usually unnecessary
- post-run: normal meal
- prioritise **~25–30 g protein**
- carbohydrate can be low to moderate
- avoid automatically replacing every calorie estimated by the watch

The aim is to recover adequately while allowing part of the exercise energy expenditure to contribute to the daily/weekly calorie deficit.

### Hard sessions

For:

- intervals
- threshold
- tempo
- long demanding runs
- races / PB attempts

carbohydrate availability should be prioritised.

The goals are:

- hit the required pace/intensity
- complete enough quality work
- replenish glycogen
- recover sufficiently
- preserve the intended training adaptation

### Practical carbohydrate periodisation

Use relatively more carbohydrate around high-intensity and long sessions.

Use relatively less around recovery / easy / FatMax days when appropriate.

Protein should **not** be deliberately restricted during weight loss.

---

## 11. Weight loss versus fat oxidation

Maximising fat oxidation during one workout is not identical to maximising long-term body-fat loss.

Long-term fat loss depends mainly on sustained energy balance.

Therefore:

- FatMax running is useful because it creates aerobic training with relatively low fatigue
- it can contribute meaningful energy expenditure
- it should not replace quality sessions required for the half-marathon goal
- aggressive post-run calorie replacement can reduce the energy deficit
- aggressive under-fuelling around important sessions can reduce training quality

The intended strategy is to create the calorie deficit mainly away from critical high-quality training windows.

## 13. Recommended app behaviour

Where training logic uses these values:

1. Never overwrite measured lactate thresholds with inferred values.
2. Store measured and estimated thresholds separately.
3. Label estimated FatMax clearly as a hypothesis.
4. Use HR as the primary target for FatMax sessions.
5. Treat pace as a secondary contextual reference.
6. Permit post-run segmentation into arbitrary time windows such as 15-minute blocks without requiring workout laps.
7. Calculate HR/pace drift across those blocks.
8. Allow future metabolic or lactate retesting to replace estimates with new measured values.
9. Treat **~4:55/km at ~167 bpm** as the current working LT2 centre for training until new evidence justifies another revision.
