# Shoe Rotation — 1:30 Half-Marathon Master Plan

**Effective from:** 10 October 2026  
**Goal race:** 21 March 2027

Footwear is now part of the training prescription. The purpose is to put routine mileage into the durable training shoes, use the plated PUMA for repeatable quality work, and protect the ASICS race shoe for sessions where outright performance or race rehearsal matters.

## Rotation

| Shoe | Primary role | Master-plan use |
|---|---|---|
| **adidas Adizero Evo SL** | Main mileage / aerobic shoe | Easy runs, long aerobic runs, recovery, easy + strides, shakeouts |
| **PUMA Deviate NITRO 3 HYROX** | Middle-fast / quality training shoe | Threshold, tempo, progression, HM-pace blocks, intervals, controlled fast parkruns |
| **ASICS Metaspeed Sky Tokyo** | Race / benchmark shoe | 5K and 10K PB attempts, benchmark races, key race-specific rehearsals, Cotswold Airport HM and the March goal HM if fit remains good |

## Selection rules

1. **Easy / aerobic / long / recovery → Evo SL.** The objective is aerobic work, not maximising shoe-assisted pace.
2. **Threshold / tempo / progression / HM pace → Deviate NITRO 3 HYROX.** This is the default quality-work shoe and absorbs repeated faster-training kilometres.
3. **PB attempt / benchmark race / goal race → Metaspeed Sky Tokyo.** Do not spend race-shoe kilometres on routine training.
4. A controlled parkrun used as training is a **PUMA** session. A formally scheduled PB/benchmark parkrun is an **ASICS** session.
5. If an actual shoe is recorded on the completed activity, the actual shoe overrides the prescription for mileage accounting.
6. If pain, fit problems, unusual slipping or altered mechanics appear, comfort and injury prevention override the rotation rule.

## Mileage accounting

Paul's Running starts automatic shoe-distance accounting from **10 October 2026**.

- The live **Running Shoes** page recalculates mileage from completed activities.
- A completed activity is first checked for actual shoe/gear metadata.
- If actual shoe metadata is absent, the activity is matched to the planned master-plan session and inherits that session's prescribed shoe.
- Mileage is derived from the completed activity distance, not from planned distance.
- Re-importing or refreshing an activity does not add duplicate distance because totals are recalculated from unique activity records.
- Earlier mileage is not guessed or silently backfilled.

### Evo SL efficiency watch

For the Evo SL, start paying particular attention to responsiveness from roughly **350–400 km**. Around **400 km** is a review point rather than an automatic retirement point. If the shoe feels flatter but remains comfortable, it can be demoted toward easy/general mileage instead of being discarded immediately.

## Current programme rule

The already-scheduled October–November programme should display the prescribed shoe alongside every running session. Future programme revisions should continue to treat footwear as part of the workout prescription so the completed-run mileage ledger remains deterministic.
